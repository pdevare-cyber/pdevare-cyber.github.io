# Pooja Devare — Cybersecurity & IT Portfolio

A responsive personal portfolio website using plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `pdevare-cyber.github.io` (or another repository name).
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Before publishing — personalise these details
- Replace the LinkedIn placeholder URL in `index.html` with your actual profile URL.
- Add a professional email address and optionally a CV download link.
- Review every experience and project description for accuracy.
- Add evidence links, screenshots and detailed write-ups to projects as they are completed.
- The Windows Event Log Analysis card is explicitly marked as planned, not completed.

## Project status and accuracy
This site distinguishes professional experience, academic work and planned independent labs. Keep that distinction when adding new work. Do not list tools as professional experience unless that accurately reflects your use of them.
